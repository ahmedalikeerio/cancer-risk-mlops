# Cancer Risk Prediction — MLOps

An end-to-end machine learning system for predicting cancer-risk categories from demographic, lifestyle, environmental, and genetic risk factors.

## Project Status

🚧 In Development

## Objectives

- Learn Hugging Face Datasets and the Hugging Face Hub
- Build a reproducible tabular ML pipeline
- Investigate and eliminate data leakage
- Compare baseline and optimized ML models
- Track experiments with MLflow
- Version datasets and pipelines with DVC
- Optimize hyperparameters with Optuna
- Register and manage models with MLflow
- Serve predictions through FastAPI
- Containerize the application with Docker
- Implement CI/CD using GitHub Actions
- Monitor data and prediction drift
- Deploy the production inference service

## Dataset

Primary dataset:

`tarekmasryo/cancer-risk-factors-data`

Source:

https://huggingface.co/datasets/tarekmasryo/cancer-risk-factors-data

The dataset contains simulated cancer-risk-related patient profiles.

## Disclaimer

This project is for educational and machine-learning engineering purposes only. It is not intended for clinical diagnosis, medical decision-making, or patient care.
